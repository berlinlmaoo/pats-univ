Pertanyaan Susulan — PATS University

Lanjutan dari lembar pertanyaan pertama (nomor 1–14). Isi kotak jawaban, atau coret kalau setuju dengan default sementara. Versi 16 Oktober 2026.

Pertanyaan ini muncul setelah Phase 0 selesai dan web dashboard mulai terbentuk. Nomor dilanjutkan dari lembar pertama supaya jawabannya bisa dirujuk bersamaan. Kalau tidak ada jawaban, kami memakai default sementara yang tertulis di tiap nomor; semuanya bisa diubah nanti.

Bagian 5

Peran & akses admin

Penting untuk dashboard
15
Perlu peran Manager Wilayah? Kalau perlu, satu wilayah berisi kota mana saja, dan siapa yang menunjuk orangnya?S1
Saat ini cuma ada dua peran admin: Super Admin (HQ, semua kota) dan Admin Kota (satu kota). Manager Wilayah akan berada di antaranya dan memegang beberapa kota sekaligus (misal Jawa Barat: Bandung + Bogor). Sebutkan juga apa saja yang boleh dia lakukan: lihat data, buat event, approve roaming, kelola admin kota, export.
Default sementara Belum ada peran ini. Tanpa jawaban, wilayah ditangani HQ.
16
Apakah Admin Kota juga perlu web dashboard, atau cukup lewat app?S2
Sekarang Admin Kota bekerja dari app HP: scan check-in, serah terima kartu, validasi redeem dan laporan PR, recap kotanya. Web dashboard hanya untuk HQ. Kalau Admin Kota (atau Manager Wilayah) juga dapat web dashboard, isinya dibatasi ke kota/wilayahnya sendiri.
Default sementara Admin Kota cukup lewat app; web dashboard hanya HQ.
17
Berapa admin per kota, dan apakah ada level crew yang hanya boleh scan?S3
Saat event bisa ada beberapa orang yang scan member di pintu. Pilihannya: semua orang itu menjadi Admin Kota penuh, atau ada peran Crew yang hanya bisa scan check-in dan validasi redeem, tanpa akses data member, recap, dan pengaturan.
Default sementara Boleh lebih dari satu Admin Kota; belum ada peran Crew.
Bagian 6

Kartu, XP, data member

18
Kalau kartu hilang atau rusak, apakah member dikenai biaya pengganti, dan berapa kali boleh diganti?S4
Kartu lama langsung dinonaktifkan permanen saat dilaporkan hilang. Kartu pengganti dicetak vendor dan di-encode lagi di HQ, jadi ada biaya kartu, cetak, dan kirim.
Default sementara Gratis, tanpa batas; pengganti masuk antrean cetak berikutnya.
19
Apakah XP punya masa berlaku?S5
Kalau ada, XP yang tidak dipakai dalam jangka tertentu hangus (misal 12 bulan sejak didapat). Ini mendorong member menukar XP, tapi perlu diberitahukan dengan jelas di app.
Default sementara XP tidak kedaluwarsa.
20
Kalau member pindah domisili, bagaimana kota asalnya diganti?S6
Kota asal menentukan grup WA, social hub, dan leaderboard kota. NIM yang sudah tercetak di kartu memuat kode kota lama.
Default sementara HQ yang mengganti kota asal; NIM dan kartu tetap, riwayat XP ikut pindah.
Bagian 7

Reservasi, roaming, privasi

21
Reservasi sofa/table: siapa yang menyetujui, dan apakah ada deposit atau minimum spend?S7
Member memilih slot dari denah venue, lalu admin kota (atau marketing venue) mengonfirmasi atau menolak lewat chat di app. Pembayaran tidak diproses di app.
Default sementara Admin kota yang konfirmasi; tanpa deposit di app, minimum spend dicatat sebagai teks per slot.
22
Berapa reservasi aktif yang boleh dimiliki satu member per event?S8
Batas ini mencegah satu orang mengunci banyak meja sekaligus.
Default sementara 1 reservasi per member per event.
23
Roaming: berapa lama akses social hub kota lain berlaku, dan berapa kali per bulan member boleh roaming?S9
Member bisa minta absen di event kota lain (disetujui Admin Kota tujuan) dan akses hub kota lain (disetujui HQ). Setelah masa berlaku habis, akses kembali ke hub asal otomatis.
Default sementara Akses hub berlaku sampai 48 jam setelah event tujuan selesai; tanpa batas jumlah per bulan.
24
Kalau member berhenti atau minta datanya dihapus, apa yang terjadi pada datanya?S10
Ini menyangkut data pribadi (nama, tanggal lahir, email, WA, foto, kehadiran). Pilihannya: data dihapus permanen, atau dianonimkan tapi angka kehadiran tetap masuk rekap.
Default sementara Akun dinonaktifkan, data pribadi dianonimkan, angka kehadiran tetap di rekap.
